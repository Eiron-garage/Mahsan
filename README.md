# 📦 מחסן מטיילי עירון

אתר המחסן: מודל תלת־ממד של המחסן, איתור פריט לפי מק״ט, ומלאי משותף לכל המכשירים בזמן אמת.
המחסן נפרד לגמרי מלוח סטטוס הרכבים: יש לו פרויקט Firebase משלו (Mahsan) וסיסמה משלו.

כתובת: https://eiron-garage.github.io/Mahsan/

## מה יש בו
- חיפוש לפי מק״ט או שם. המצלמה טסה אל המדף, והתא נדלק בצהוב.
- הוספה, העברת מיקום ועדכון כמות. כל שינוי מופיע מיד אצל כולם, עם השם של מי שעשה אותו.
- יומן פעילות, מונים של "אזל" ו"מלאי נמוך", וייצוא של כל המלאי לאקסל.
- ייבוא רשימת מלאי מ־Google Sheets או מאקסל (CSV).
- עובד גם בטלפון. מומלץ להוסיף למסך הבית:
  - **אייפון (Safari):** כפתור השיתוף ← "הוסף למסך הבית".
  - **אנדרואיד (Chrome):** תפריט ⋮ ← "הוספה למסך הבית".

## קבצים
- `index.html` הוא האתר עצמו. מבנה המחסן (מספר המדפים, הקומות והארונות) מוגדר בבלוק `Warehouse layout`.
- `config.js` מכיל את פרטי החיבור ל־Firebase ואת המייל של חשבון המחסן. הסיסמה **לא** נשמרת כאן.
- `firestore.rules` הם חוקי האבטחה. מדביקים אותם ב־Firebase ← Firestore ← Rules.

## החלפת סיסמה
Firebase ← Authentication ← Users ← ⋮ ← Reset password. אחרי ההחלפה כל המכשירים יצטרכו להיכנס מחדש.
